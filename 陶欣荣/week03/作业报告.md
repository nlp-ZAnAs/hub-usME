# 12 类语种分类模型训练 · 作业报告

## 0. 结论

- 已完成 12 类语种分类模型的训练、评测和存档。
- 测试集 1800 条：**accuracy = 0.9556，macro-F1 = 0.9559**；随机猜只有 8.3%。
- 12 类字符表 **3276 个字符**（含 `<PAD>`/`<UNK>`），前 **803 个实际字符**覆盖 95% 的字符出现次数，与 `DATA_CARD.md` 一致。
- 最终模型：`langid_rnn_v12.pt`；字符表：`data/langid/vocab/vocab_v12.txt`。

12 个标签：`ar` 阿拉伯语、`en` 英语、`es` 西班牙语、`hi` 印地语、`ja` 日语、`ko` 韩语、`pt` 葡萄牙语、`ru` 俄语、`th` 泰语、`tr` 土耳其语、`vi` 越南语、`zh` 中文。


## 2. 作业完成步骤

1. **建字符表**：`build_vocab_v12.py` 读 `v12/train.csv`，对每句做 `normalize()`，统计字符频率；`<PAD>`=0、`<UNK>`=1，其余按 `(-出现次数, 字符)` 排序编号，写出 `字符<TAB>id<TAB>出现次数`。结果 3276 个字符。
2. **扩类别**：`--labels ar en es hi ja ko pt ru th tr vi zh`，模型输出维度 `len(labels)=12`；脚本会检查数据标签与 `--labels` 完全一致。
3. **训练**：12 类数据 9600/1200/1800；Adam lr=1e-3，batch=64，dropout=0.3，12 epochs，seed=42，CPU 单线程，约 12 秒。按 dev 选最优 epoch（epoch 9，dev_acc=0.9725），再在 test 上只评一次。
4. **评测**：测试集、难度切片、开放集、混排 demo 全部运行并保留日志。

模型结构：`Embedding(3276,64) → RNN(64,64) → masked MaxPool → LayerNorm(64) → Dropout(0.3) → Linear(64,12)`，参数量 **218,892**。

### 3.5 难度切片（1300 条）

| slice | 条数 | accuracy | 说明 |
|---|---:|---:|---|
| short | 600 | 0.865 | 2–7 字符短句 |
| nodeaccent | 600 | 0.745 | 去重音，vi 仅 40/120 |
| nokana | 100 | 0.260 | 日语去假名，59 条被判成 zh |

`nokana` 说明：假名是区分日语和中文的关键；去掉假名后只剩汉字，字符级模型几乎失去线索，与数据卡“假名占日语字符出现次数 71%”一致。

### 3.6 开放集拒识（400 条未见语种）

阈值取 dev max(softmax) 的 5% 分位 = **0.691**；正常输入保留 95.0%，开放集拒识 35.0%。开放集平均置信度 0.783，正常输入 0.961。

| 未见语种 | 平均置信度 | 主要误判 |
|---|---:|---|
| bg 保加利亚语 | 1.00 | 100 条全部 → ru（同为西里尔字母） |
| ur 乌尔都语 | 0.94 | 96 → ar（同为阿拉伯字母） |
| sw 斯瓦希里语 | 0.78 | 60 → en，24 → tr，12 → es |
| el 希腊语 | 0.41 | 全部 → ja（训练集没有希腊字母） |

同书写系统的未见语言置信度接近 1.0，说明只靠 softmax 阈值拒识不够；需要 unknown 类、energy/entropy 或字符 n-gram 分布外检测。

### 3.7 模型 vs 纯规则

20 条手写混排句：模型 **18/20**，纯规则 **9/20**。v12 整张测试集：模型 **0.9556**，纯规则 **0.6600**。规则把 es/pt/tr/vi 全部判成 en，直接 0 分。

模型仍错的两条中文混排：
- “建议用 pytorch 而不是 tensorflow 来跑这个 demo” → en(0.74)
- “先 git commit 再 push 上去，别直接改 master” → en(0.74)

这两句拉丁字母占绝对多数，字符级模型看到的主体确实是英文；解决需要词级/子词级信息、字符 n-gram 或注意力。

## 4. 误差分析

1. **es ↔ pt 是主要错误来源**：50 条互错，占全部错误六成以上；共享大量功能词和词形，短句最难分。
2. **短文本信息不足**：8–12 字符档 90.3%，2–7 字符 short 切片 86.5%。
3. **重音符号很重要**：nodeaccent 74.5%，越南语仅 33.3%；去重音后拉丁语种互相靠拢。
4. **日语假名不可替代**：nokana 26.0%，日语大量被判成中文。
5. **开放集拒识是短板**：同书写系统的未见语言会被高置信度误判。
6. **混排要看主体**：英文词占多数时，中文技术口语会被判成英语；训练数据以单语为主。

本机已安装 Python 3.12 + torch 2.9.1+cpu。若 `python` 已在 PATH，把 `$py` 换成 `python` 即可。

```powershell
$py = "$env:LOCALAPPDATA\Programs\Python312\python.exe"
cd "D:\BaiduNetdiskDownload\week3-深度学习处理文本\week3-深度学习常用组件\语种识别实战"

& $py build_vocab_v12.py
& $py train_langid_cls.py --data-dir data/langid/v12 --vocab data/langid/vocab/vocab_v12.txt --labels ar en es hi ja ko pt ru th tr vi zh --epochs 12 --save langid_rnn_v12.pt
& $py eval_langid.py --model langid_rnn_v12.pt --data-dir data/langid/v12
& $py eval_langid.py --model langid_rnn_v12.pt --data-dir data/langid/v12 --split test_hard
& $py eval_langid.py --model langid_rnn_v12.pt --data-dir data/langid/v12 --split none --openset
& $py demo_mixed_text.py --model langid_rnn_v12.pt --data-dir data/langid/v12
```

## 6. 可以继续改进

| 方向 | 预期收益 |
|---|---|
| 双向 LSTM/GRU | 利用左右上下文，es/pt、tr/vi 通常提升 1–2 点。 |
| 字符 n-gram + CNN | 建模局部拼写模式，对短文本、去重音更稳。 |
| 子词/BPE | 缓解中文几千字 vs 拉丁几十个字母的信息密度差异。 |
| 更多数据/增强 | 每类 800 条偏少，短文本和重音变体可增强。 |
| unknown 类/energy 拒识 | 改善开放集，避免 bg→ru、ur→ar。 |
| 集成/专门二分类 | 针对 es/pt 高混淆对做后处理。 |
