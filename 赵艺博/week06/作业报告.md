# 第六周作业：数据接入与分流（自己做实验）

依据课件收口页：**自己做实验，可以换数据集 / 换预训练模型 / 换 API**。  
本组选择：**换预训练模型**（`bert-base-chinese` ↔ `chinese-roberta-wwm-ext`），并保留规则、TF-IDF 作基线。

## 1. 实验设置

| 项 | 设置 |
|----|------|
| 数据 | CLUE TNEWS（15 类新闻短标题） |
| 训练 | 分层抽样 **12,000** 条（seed=42），2 epoch，batch=16，**CPU** |
| 终评 | 去重干净验证集 **500** 条（seed=42，与课包一致） |
| 指标 | Accuracy、Macro-F1 |
| 硬件 | Intel Arc B580；`torch 2.15.0+xpu` 反传不稳，训练走 CPU |

类别加权为课包 `train_bert.py` **默认开启**（随 L2 的训练技巧，非另换模型）。

## 2. 结果（干净验证 500 条）

| 方法 | 准确率 | Macro-F1 |
|------|--------|----------|
| 规则 / 关键词（L0） | 0.126 | 0.0716 |
| TF-IDF + LinearSVC（L1） | 0.512 | 0.4721 |
| BERT：`bert-base-chinese`（L2） | **0.554** | **0.5388** |
| RoBERTa：`chinese-roberta-wwm-ext`（L2） | 0.532 | 0.5206 |

训练期选模（未去重 `val[:500]`，仅参考）：BERT 最佳 0.5421；RoBERTa 最佳 0.5622。  
终评以干净集为准：**本设置下 bert-base 略优于 RoBERTa**。

### 结论（换预训练）

1. 短文本 + 封闭标签：L2 微调明显优于 L0/L1。  
2. 换底座不一定涨点；同预算下需用**同一干净验证集**比，不能只看训练期 val。  
3. 本任务瓶颈更接近标签边界与数据，而不是「换一个同级 encoder」。

## 3. 课后作业补充：易混类与解决思路

对 BERT 预测做混淆统计，本批 500 条上最突出的一对是：

**科技 → 财经（真实=科技、预测=财经，约 18 次）**

- **原因**：短标题里公司名、股价、融资、财报常同时出现，「科技公司的财经事件」边界糊。  
- **打算怎么解决**（按课件：先改口径/补数据，再换方法）：  
  1. **改标签口径**：投研场景可把「科技公司的资本事件」并入金融组，或增加「科技×财经」复合标签，避免硬拆 15 类。  
  2. **补数据**：专补带「发布会/芯片」但无股价表述、以及带「财报/并购」的科技公司标题，拉开两类分布。  
  3. **下游能力**：下一周信息抽取抽「主体 + 事件类型」；分类只做粗分流，细类交给抽取。  
  4. **系统侧**：低置信（科技/财经 概率接近）进 `review`，不直接进研究队列。

次易混：**军事 ↔ 国际**（制裁、军演、芯片出口管制等短标题两侧都像）。处理同上：实体/事件抽取 + 低置信人工/LLM 兜底。

## 4. 简历口径（用本机数字）

在约 5.3 万条中文新闻（TNEWS）上做投研分流实验：对比规则 / TF-IDF / BERT / RoBERTa；干净验证 500 条上最优为 **BERT Macro-F1 0.5388**（准确率 0.554），较 TF-IDF 基线 **+6.7pt**；单条推理约 **20 ms**（CPU）。另做换预训练对照：同设置下 RoBERTa 为 0.5206，说明换底座未必涨点，需固定评测口径。
