# 第七周作业：金融公告事件抽取（方法对比 + 换模型）

任务：一句公告 → 一个结构化事件（类型 / 触发词 / 论元）。  
评测：`common/evaluate_events.py`，dev **930** 句（LLM 线为 n=200 子集，已标注）。

依据课件收口页课后作业 1–5；并完成「换不同预训练模型」对照。

## 1. 实验设置

| 项 | 设置 |
|----|------|
| 数据 | DuEE-Fin 派生；train 5747 / dev 930 |
| 自训换模型 | BERT+Linear / RoBERTa+Linear，3 epoch，max_len=256，**XPU（Arc B580）** |
| 课包复现数字 | 规则 / BERT+CRF / 两段式 / LLM（同口径已有 metrics） |

## 2. 四路方法对比（作业第 1 项）

### 2.1 主表（判别式全量 930；LLM 为 n200）

| 方法 | 触发词 F1 | 论元 F1 | 事件级 F1 | 备注 |
|------|-----------|---------|-----------|------|
| L0 规则（词典+正则） | 0.6168 | 0.1740 | 0.0161 | 本机重跑一致 |
| L2 BERT+Linear（课包） | 0.8293 | 0.5630 | 0.1564 | |
| L2 BERT+CRF（课包） | **0.8320** | **0.5815** | 0.1697 | 主线 |
| L2 两段式流水线 | 0.6769 | 0.3690 | 0.0957 | 拆细未涨 |
| L3 API zero-shot（n200） | 0.7789 | 0.5224 | 0.0402 | |
| L4 Qwen LoRA SFT（n200） | 0.9000 | **0.6971** | **0.1850** | 子集口径 |

结论：规则只能兜底；预训练判别式论元 F1 明显高于 BiLSTM/规则；CRF 相对 Linear 小幅涨；两段式本任务变差；LLM LoRA 在 n200 上论元最高，但事件级仍难、成本不同。

### 2.2 换预训练模型（自训，同设置 Linear）

| 模型 | 触发词 F1 | 论元 F1 | 事件级 F1 | 训练耗时 |
|------|-----------|---------|-----------|----------|
| `bert-base-chinese` | **0.8296** | **0.5630** | 0.1655 | ~274 s |
| `chinese-roberta-wwm-ext` | 0.8166 | 0.5608 | **0.1736** | ~274 s |

结论：同架构、同训练预算下，**换 RoBERTa 并未稳定全面超过 BERT**；触发词/论元略低，事件级略高。抽取任务上「换底座」收益有限，解码约束/数据边界更关键（课件结论一致）。
