# 第七周作业：换模型做事件抽取对比

任务：一句金融公告 → 结构化事件（类型 / 触发词 / 论元）。  
作业内容：**同一设置下更换预训练模型**，对比抽取效果。

## 1. 实验设置

| 项 | 设置 |
|----|------|
| 数据 | DuEE-Fin 派生；train 5747 / dev **930** |
| 方法 | BERT 序列标注 + **Linear** 解码 |
| 对照模型 | `bert-base-chinese` vs `chinese-roberta-wwm-ext` |
| 训练 | 3 epoch，max_len=256，batch=32，**XPU（Arc B580）** |
| 评测 | `common/evaluate_events.py`（触发词 / 论元 / 事件级 F1） |

## 2. 结果

| 模型 | 触发词 F1 | 论元 F1 | 事件级 F1 | 训练耗时 |
|------|-----------|---------|-----------|----------|
| `bert-base-chinese` | **0.8296** | **0.5630** | 0.1655 | ~274 s |
| `chinese-roberta-wwm-ext` | 0.8166 | 0.5608 | **0.1736** | ~274 s |

## 3. 结论

同架构、同训练预算下，**换 RoBERTa 没有全面超过 BERT**：触发词与论元 F1 略低，事件级略高。  
对本抽取任务，「换底座」收益有限，更关键的仍是标签边界与解码约束。
