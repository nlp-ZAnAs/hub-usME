# Week03 作业：12 类语种识别

## 作业要求

课堂给的 `train_langid_cls.py` 是 **8 语种**版（`LABELS` 写死 8 个、字符表直接读 `vocab_v8.txt`）。
本次作业要求在**同一套模型结构**上，把语种扩展到 **12 类**：

| 课堂 8 类 | 作业新增 4 类 |
|---|---|
| ar 阿拉伯 / en 英 / es 西 / hi 印地 / ja 日 / pt 葡 / ru 俄 / zh 中 | ko 韩 / th 泰 / tr 土耳其 / vi 越南 |

课程数据包里 `data/langid/v12/` 就是这 12 类的数据（train 9600 / dev 1200 / test 1800，每类均衡 800/100/150），
但**没有提供 v12 的字符表**，必须按课堂代码自己从 `v12/train.csv` 统计生成。

## 相对课堂 8 类版改了什么

1. **`LABELS` 8 → 12**：模型输出维度 = `len(LABELS)`，少一个语种，多出来的句子没有对应输出格子，
   脚本里加了检查，数据里出现 `LABELS` 之外的标签会直接报错退出。
2. **字符表不能再用 `vocab_v8.txt`**：那张表里没有韩文、泰文、越南语、土耳其语的字符，
   沿用会让这些字全部落到 1 号 `<UNK>`，模型等于睁眼瞎。
   → 用 `build_char_vocab()` 从 `v12/train.csv` 现场统计，写成同样格式的 `vocab_v12.txt`。
3. **数据目录 → v12**，并补了训练曲线、逐类准确率、12×12 混淆矩阵、dev/test 的 `<UNK>` 占比检查。

模型结构完全沿用课堂：`Embedding → RNN → 掩码 MaxPool → LayerNorm → Dropout → Linear`，
`CrossEntropyLoss` + `Adam(lr=1e-3)`，单线程 CPU。

## 实测结果

- 数据：train 9600 / dev 1200 / test 1800，12 类均衡；随机猜基准 **8.3%**
- 字符表：**3276** 个字符，字符出现总次数 198,121，前 **803** 个覆盖 95%
- `<UNK>` 占比：dev **0.4452%** / test **0.5907%**（词表来自 train，dev/test 有少量没见过的字符属于正常）
- 模型参数量：**218,892**
- 训练：30 epoch，**53 秒**（1 线程 CPU）
- **测试集 accuracy = 0.9733，macro-F1 = 0.9736**

| 语种 | 准确率 | 语种 | 准确率 |
|---|---|---|---|
| ar 阿拉伯 | 1.000 (150/150) | ko 韩 | 1.000 (150/150) |
| en 英 | 0.907 (136/150) | pt 葡 | 0.867 (130/150) |
| es 西 | 0.967 (145/150) | ru 俄 | 1.000 (150/150) |
| hi 印地 | 1.000 (150/150) | th 泰 | 1.000 (150/150) |
| ja 日 | 0.993 (149/150) | tr 土耳其 | 0.960 (144/150) |
| vi 越南 | 0.987 (148/150) | zh 中 | 1.000 (150/150) |

### 错在哪

| 真实 → 预测 | 条数 | 原因 |
|---|---|---|
| pt → es | 19 | 同属拉丁字母，葡语和西语词形高度相似，短句尤其难分 |
| en → es | 7 | 英语短句里的拉丁字母特征被拉向罗曼语族 |
| en → tr | 6 | 同上，土耳其语也用拉丁字母（新增语种带来的新混淆） |
| tr → es | 3 | 同上 |
| es → pt | 3 | 反方向 |

结论：**12 类的难点全部集中在「同一套拉丁字母」的 es/pt/en/tr 之间**，
新增的 ko（谚文）、th（泰文）、vi 的准确率都在 0.98 以上 —— 书写系统不同，
字符级模型几乎一眼就能分开。这也印证了课堂上的说法：字符级的难点不是"语种多"，
而是"字母表相同"。

## 备注

- 老师的 `eval_langid.py` 是从 `train_langid_cls`（8 类版）里 import 模型和评测函数的，
  本脚本把同样的函数实现在自己文件里，函数名保持一致（`LangIDClassifier` / `encode` / `macro_f1` 等）；
  要让老师的评测脚本直接跑这份 12 类模型，只需把 `from train_langid_cls import ...`
  改成 `from train_langid_cls_v12 import ...`（checkpoint 里已自带 vocab 和 labels）。
- 试过「按 dev 最优轮次回滚权重」，结果反而更差（dev 只有 1200 条，0.9775 这类高分是噪声尖峰，
  回滚后测试集掉到 0.9622），所以最终版保持朴素做法：训练固定轮数、用最后一轮权重。
- 训练轮数实测：20 轮 ≈ 96.8%、30 轮 ≈ 97.3%、40 轮 ≈ 97.2%，30 轮之后已进入平台区。
