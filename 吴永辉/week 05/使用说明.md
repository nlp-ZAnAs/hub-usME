# 本地问答界面（sft_chat_model.pt）

把 `sft_chat_model.pt` 变成可以打字对话的网页界面。全程本地推理，不联网、不需要 API Key。

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `chat_ui.py` | 问答界面主程序（Python 标准库 + torch，无其他依赖） |
| `启动问答界面.bat` | 双击启动（自动开浏览器） |
| `sft_chat_model.pt` | 你训练好的 SFT 模型（本程序直接读取） |
| `sft_val.jsonl` | 用来生成首页的示例问题，可选 |

## 启动方式

**方式一（最简单）**：双击 `启动问答界面.bat`，浏览器会自动打开 `http://127.0.0.1:8000/`。

**方式二（命令行）**：

```bat
cd /d "F:\Ai学习\作业\week 05"
F:\anaconda3\envs\py312\python.exe chat_ui.py
```

**方式三（换个端口 / 强制 CPU）**：

```bat
python chat_ui.py --port 8080
python chat_ui.py --device cpu
python chat_ui.py --no-browser        :: 只起服务，不开浏览器
```

关闭：在启动窗口按 `Ctrl+C`，或直接关掉那个黑窗口。

## 界面功能

- **流式输出**：字是一个一个蹦出来的，不用等整段生成完（首字延迟约 10 毫秒）。
- **⚙ 参数**：可实时调整
  - 温度（0 = 贪心，越大越发散，默认 0.8）
  - Top-K（默认 40）
  - 重复惩罚（默认 1.15，抑制「1. 1. 1.」式复读）
  - 最多字数（默认 160）
- **示例问题**：首页的胶囊按钮来自 `sft_val.jsonl`。
- **停止**：生成中途可以打断。
- **直接提问链接**：`http://127.0.0.1:8000/?q=你要问的问题` 打开即自动提问，适合做演示。
- 会话轮次只是界面上的记录，**每次提问都是独立的**（不带上文），因为该模型是按单轮 `用户：…\n助手：…` 训练的。

## 命令行参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--model` | 同目录 `sft_chat_model.pt` | 权重路径 |
| `--host` | `127.0.0.1` | 只允许本机访问，改 `0.0.0.0` 可供局域网使用 |
| `--port` | `8000` | 被占用时自动顺延最多 20 个端口 |
| `--device` | `auto` | `auto` / `cpu` / `cuda` |
| `--no-browser` | 关 | 不自动打开浏览器 |

## HTTP 接口（想自己写前端时可用）

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/info` | GET | 模型信息（参数量、设备、val_loss 等） |
| `/api/examples` | GET | 示例问题 |
| `/api/chat` | POST | 一次性返回，`{"q": "...", "temperature": 0.8}` → `{"text": "..."}` |
| `/api/chat_stream` | POST | NDJSON 流式，逐行推送 `{"t": "字"}`，以 `{"done": true}` 结束 |

## 关于效果：请先看这一段

这个模型是**字符级的两层 RNN**（embed 128 / hidden 256 / 词表 4097 / 共 181 万参数），从 `best_model_rnn.pt` 继续 SFT 而来。实测：

- 训练集前 200 条 loss ≈ 3.87，验证集 loss ≈ 3.85，两者几乎一样；
- 也就是说模型**还没有真正学会「按问题作答」，只是学到了答案的常见句式**（例如总往「这组数字的平均值是…」上靠）。

界面本身没有问题（接口、流式、渲染都验证过），是模型训练得不够。想让它答得像样，改 SFT 脚本即可，界面不用动：

1. `--learning-rate` 从 `1e-4` 提到 `1e-3`（中文新字符的 embedding 是随机初始化的，小学习率几乎学不动）；
2. `--epochs` 从 5 提到 20~50，并盯着 val_loss；
3. 数据从 3000 条加到 1 万条以上，答案句式尽量多样；
4. 仍不满意就换更强的基座（GRU/LSTM 加大、或直接上小 Transformer）。

## 常见问题

- **双击没反应 / 一闪而过**：多半是没装 torch。用 `F:\anaconda3\envs\py312\python.exe -c "import torch"` 验证，或修改 bat 里的 `PY` 路径。
- **提示端口被占用**：程序会自动换端口，看窗口里打印的真实地址即可。
- **想让局域网其他设备访问**：`python chat_ui.py --host 0.0.0.0`，再用本机 IP 访问。
- **控制台中文乱码**：只在把输出重定向到管道时出现，双击运行或正常命令行窗口里是好的。
