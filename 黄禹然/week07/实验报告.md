# 第七周作业：金融公告事件抽取——多方法效果对比实验报告

## 一、任务定义与实验目标

**任务**：给定一句金融公告原文，抽出一个结构化事件 = 事件类型 + 触发词 span + 若干「角色 → 论元」span。

**数据来源**：DuEE-Fin 派生数据集（13 个事件类型 / 92 个类型-角色槽位 / 61 个去重角色名）。
- 训练集 5,747 句；主评测集 dev_extract **930 句**；去重复版 dev_extract_clean **920 句**。
- 评测使用项目统一评测函数 `common/evaluate_events.py`，三级 F1（触发词 / 论元 / 事件级）+ 类型 macro F1。

**实验目标**：拆解"**换不同模型 / API / 数据集**"对抽取效果的影响，在同一评测口径下对比各种方法的效果差异。

**完成情况总览**：

| 要求维度 | 状态 | 说明 |
|---|---|---|
| 换不同模型 | ✅ 完成 | BERT → RoBERTa，完整训练 + 硬约束复评 |
| 换数据集 | ✅ 完成 | 全量 dev（930）→ 去重复 dev（920）成对复评 |
| 换 API | ⚠️ 未实测 | 无 API key；引用项目预置的历史基线数据，已标注来源 |
| 对比各种方法 | ✅ 完成 | 规则 / BiLSTM-CRF / BERT / RoBERTa / 两段式 / LLM，共 11 组结果 |

## 二、实验环境与方法

- 硬件：10 核 CPU（无 GPU），RoBERTa 训练约 3.6 小时（12,942 秒）。
- 软件：Python 3.13 + torch 2.15.0+cpu + transformers 5.24.0；`OMP_NUM_THREADS=8` 限制线程。
- 公平性：所有方法共用同一金标、同一评测函数；换模型实验只改 `--bert_path` 一个变量，超参（epochs=3、lr=2e-5、max_len=256、seed=42）与 BERT 基线完全一致。

**RoBERTa 训练命令**（换模型的核心实验）：

```powershell
$env:OMP_NUM_THREADS="8"
python bert/train.py --bert_path pretrain_models/chinese-roberta-wwm-ext --run_name roberta_crf_256 --device cpu
```

之所以只换路径就能跑：RoBERTa-wwm-ext 与 bert-base-chinese **同为 12 层 / 768 维 / 21128 词表的 BERT 架构**，仅预训练方式不同（全词掩码），因此 `BertModel.from_pretrained()` 可直接加载权重。

**硬约束复评命令**（零训练，解码期禁止非法 BIO 转移）：

```powershell
python bert/evaluate_hard_constraint.py --ckpt outputs/checkpoints/roberta_crf_256.pt --run_name roberta_crf_256_hard --soft_json roberta_crf_256 --device cpu
```

## 三、实验结果

### 3.1 主表：各方法对比（dev 930，统一评测口径）

| 方法 | 触发词F1 | 论元F1 | 事件级F1 | 类型macroF1 | 延迟(ms/句) | 非法序列占比 |
|---|---|---|---|---|---|---|
| L0 规则（词典+正则） | 0.6168 | 0.1740 | 0.0161 | 0.8118 | 0.695 | - |
| L1 BiLSTM-CRF（无预训练） | 0.8165 | 0.4634 | 0.0885 | 0.7306 | 20.56 | 48.82% |
| L2 BERT+Linear（联合） | 0.8293 | 0.5630 | 0.1564 | 0.7654 | 11.26 | 66.88% |
| L2 BERT+CRF（联合） | 0.8320 | 0.5815 | 0.1697 | 0.7741 | 74.28 | 62.47% |
| L2 两段式流水线 | 0.6769 | 0.3690 | 0.0957 | 0.5619 | 49.87 | - |
| **L2 RoBERTa+CRF（本次实验）** | 0.8098 | **0.5749** | **0.1770** | 0.7548 | 137.77 | 66.99% |

> 延迟列含 CPU/GPU 硬件差异（BERT 基线为 GPU 历史结果，RoBERTa 为 CPU 实测），此列不可直接横比；F1 类指标不受硬件影响，可比。

### 3.2 消融实验：解码期硬约束

| 方法 | 触发词F1 | 论元F1 | 事件级F1 | 非法序列占比 |
|---|---|---|---|---|
| 消融：max_len 128 | 0.8209 | 0.5254 | 0.1453 | 61.83% |
| 消融：BERT 前 4 层 | 0.7793 | 0.3495 | 0.0535 | 86.67% |
| BERT+CRF + 硬约束 | 0.8464 | 0.6566 | 0.2177 | 7.42% |
| **RoBERTa+CRF + 硬约束（本次实验）** | 0.8294 | **0.6666** | **0.2370** | 8.06% |

### 3.3 换模型：BERT → RoBERTa 的差异

| 对比 | BERT+CRF | RoBERTa+CRF | 差值 |
|---|---|---|---|
| 软约束 论元F1 | 0.5815 | 0.5749 | **-0.0066** |
| 软约束 触发词F1 | 0.8320 | 0.8098 | -0.0222 |
| 软约束 事件级F1 | 0.1697 | 0.1770 | +0.0073 |
| 硬约束 论元F1 | 0.6566 | 0.6666 | **+0.0100** |
| 硬约束 事件级F1 | 0.2177 | 0.2370 | **+0.0193** |

**结论**：
1. **单纯换更强预训练权重，收益不明显甚至略降**（软约束论元 -0.0066）。RoBERTa-wwm-ext 与 BERT 架构、词表、领域高度重合，其全词掩码的微弱优势被噪声淹没——说明该任务的瓶颈不在编码器。
2. **硬约束是跨模型稳定的收益**：RoBERTa 自身 +9.2pp（0.5749→0.6666），比 BERT 的 +7.5pp 更大；非法序列 623 句 → 75 句。它零训练、零参数，只是解码期禁止非法 BIO 转移，本质是避免非法解码破坏 span 边界。
3. **加硬约束后 RoBERTa 反超**（论元 +0.0100、事件级 +0.0193）——"哪个模型更好"依赖于解码方式，这是一个比单纯排名更有价值的发现有。

### 3.4 换数据集：全量 dev → 去重复 dev

用项目自带的 `dev_extract_clean.jsonl`（920 句，剔除与训练集文本重复的 10 句）对两个硬约束模型复评：

| 模型 | 全量 dev（930）论元F1 | clean dev（920）论元F1 | 变化 |
|---|---|---|---|
| BERT+CRF+硬约束 | 0.6566 | 0.6574 | +0.0008 |
| RoBERTa+CRF+硬约束 | 0.6666 | 0.6672 | +0.0006 |

**结论**：换数据集后指标几乎不变，说明模型效果不是靠 train/dev 重复句子虚高撑起来的，结论稳健。（抽取集仅剔除 10 条重复，检测集才是 487 条，故对抽取指标影响本来就小。）

## 四、总体结论

1. **规则基线**（论元 0.1740）证明零模型能覆盖大部分触发词（命中率 99.8%）但填不满槽位，主要失败是幻觉填充（arg_spurious 55.6%）——语义角色归属是真正的技术壁垒。
2. **预训练/建模带来主提升**：论元 0.1740 → 0.4634（+0.289）→ 0.5815（+0.118）。
3. **换编码器收益有限**：RoBERTa 相对 BERT 软约束下略低、硬约束下略高，差异均在 ±0.02 以内，编码器不是当前瓶颈。
4. **解码期硬约束是性价比最高的改进**：跨 BERT / RoBERTa 均带来 +7~9pp 论元 F1，零训练成本。
5. **两段式拆分反而更差**（0.3690 vs 0.5815）：训练预算被切碎（每个专家每 epoch 仅 3~31 步），非结构本身问题。
6. **生成式微调上限最高**（LoRA 0.6971，n200），但本次未实测。
