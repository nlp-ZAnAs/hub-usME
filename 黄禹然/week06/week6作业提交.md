# week6 作业提交：换基座实验 —— BERT vs 中文 RoBERTa

> 运行环境：Windows CPU（无独立显卡），torch 2.15.0+cpu / transformers 5.24.0，固定 seed=42。
> 受算力限制采用**减量复现**方案（每 epoch 100 步 × 3 epoch，评测 clean val 前 1,000 条），实验设计与参考答案完全一致：同数据、同超参、同 seed，**只换预训练基座**这一个变量。

---

## 一、实验设计：为什么这是一个"干净的对照实验"

两个基座的选择有讲究：`hfl/chinese-roberta-wwm-ext` 的 config.json 里 `model_type` 仍然是 `bert`——它是"用 RoBERTa 的训练配方（动态掩码 / 去 NSP / 全词掩码 / 更大语料）去训 BERT 结构"的产物，与 `bert-base-chinese` **层数（12）、隐层（768）、词表（21128）、参数量（102.3M）完全一样**。因此换基座后推理成本、训练耗时几乎不变，提升可以干净地归因于"预训练见过什么、怎么学"，而不是"模型更大"。

### 作业代码相对课件 `train_bert.py` 的 4 处差异（及其作用）

| # | 差异 | 课件版的问题 | 作业版的修复 | 不改会怎样 |
|---|---|---|---|---|
| ① | `--model` / `--tag` 参数化 + AutoModel | 基座路径写死（`bert_path()`），无法换模型，产物文件名固定 | 基座变成命令行参数，产物按基座名命名（`<tag>_log.json` / `<tag>_pred.json`）并存互不覆盖；用 `AutoModel` 按 config 自动选模型类 | 要么没法换基座，要么改源码切换时把第一次的产物覆盖，对比无从谈起 |
| ② | `set_seed()` 固定四路随机源 | 无 seed 参数：分类头随机初始化、DataLoader 洗牌顺序每次运行都不同 | `random` / `numpy` / `torch` / `torch.cuda` 四个随机源统一固定为 42，两个基座看到完全相同的初始化与 batch 顺序 | 两次运行本身的波动（实验方差）可能比换基座的效应（+0.01）还大，对比结果是噪声 |
| ③ | 评测统一 `clean_val` | 直接在全量 val（10,000 条，含 1,099 条与训练集完全重复）上评测，数字虚高且虚高幅度因方法而异（TF-IDF 虚高 3 点、BERT 虚高 1.7 点） | 评测前先 `clean_val()` 去重，与课件所有方法的横向对比表同一把尺子 | 验证集 11% 是"开卷题"，指标虚高且不可比 |
| ④ | 保存逐条预测 `_pred.json`；权重默认不存 | 只存模型权重（390MB），没有逐条预测 | 最优 epoch 的逐条真实标签+预测存成 `_pred.json`，供 `compare_base_models.py` 做配对 bootstrap；权重改为 `--save` 可选 | 汇总 F1 数字无法做逐条翻转分析，显著性检验无从下手；权重无人复用白占 800MB |

四处差异的共同主题：**控制变量**——①让唯一的实验变量是基座，②封死随机性这个隐藏变量，③统一度量衡，④把证据粒度做到逐条。

## 二、实验结果

### 2.1 主结果：参考结果 vs 本次减量复现

| 项 | 参考结果（全量，GPU） | 本次减量复现（CPU） |
|---|---|---|
| 训练规模 | 834 步/epoch × 3 | 100 步/epoch × 3（约 12% 训练量） |
| 评测集 | clean val 8,901 条 | clean val 1,000 条 |
| BERT Accuracy / Macro-F1 | 0.5420 / **0.5344** | 0.5190 / **0.5135** |
| RoBERTa Accuracy / Macro-F1 | 0.5490 / **0.5444** | 0.5390 / **0.5312** |

| 训练耗时 | 831s vs 824s（几乎相同） | 43.2 min vs 51.3 min |

## 三、回答作业三问：差多少、差在哪、值不值得换

### 3.1 差多少

换 RoBERTa 提升 **ΔMacro-F1 = +0.0177**（本次复现）/ **+0.0100**（参考全量）。但注意置信区间：本次复现的 95% 区间 **[-0.0033, +0.0378] 跨 0**，按统计标准**不足以断言"RoBERTa 显著更强"**；参考结果（8,901 条评测）区间 [+0.0019, +0.0178] 也只是勉强显著。两次实验方向完全一致，**结论应当表述为："方向可信（RoBERTa 更好），幅度不确定（约 +0.2 ~ +1.8 点），本次减量复现因评测样本量小而证据强度不足"**——区间宽度由评测样本量决定（1,000 条 vs 8,901 条），这正是"差 0.01 算不算提升"必须用 bootstrap 量化、而不能只看小数点后第三位的原因。

### 3.2 差在哪

参考结果（全量）中增益集中在**样本最少的类别**：证券 +5.3、财经 +3.5、农业 +3.0——恰好是"样本最少（证券仅 257 条，与最多类差 23 倍）+ 标签口径最重叠（财经↔证券）"的重灾区；而文化 -2.5、科技 -0.4 反而下降。本次减量复现中增益类别（故事 +5.7、房产 +5.2、科技 +4.6）与参考仅农业重合——**这不是矛盾，而是小样本下逐类 F1 的噪声**：1,000 条评测集里证券类只摊到十几条，单类 F1 就是几道题的分差。两次实验共同支持的可信结论是：**基座带来的增益是"语言知识"层面的（RoBERTa 见过更多财经/证券语料，词义区分更细），对长尾类最值钱；但它补不了标签口径本身的歧义，具体哪一类涨多少在单次小样本实验里不可信**。

### 3.3 值不值得换

**值得**，理由有三：

1. **零工程成本**：代码只改"加载哪个模型"一处（作业版甚至只需换一个命令行参数），不用重新标注数据；
2. **零额外推理/训练成本**：两个基座参数量相同（102.3M），显存、训练耗时几乎相同（参考结果 831s vs 824s）；
3. **横向性价比最高**：与课上其它手段对比——类别加权（尾部 recall +15pp，但宏观增量有限）、Label Smoothing（-0.7）、Focal（±0）、FGM 对抗（+0.02）——换基座的 +1.0 点是这些手段中最高的，仅次于"补数据"（+1.9~+4.9，但要标注成本）。

**但增益有上限**：换基座提升的是"预训练语言知识"，它救的是"被忽视的长尾类"，补不了"标签口径本身的歧义"。想让整体再上台阶，正确顺序是：**先补数据/理口径 → 再换基座 → 最后才调 loss 和对抗训练这类小旋钮**。

### 3.4 附加发现：两个反常识细节

1. **参考结果中 RoBERTa 在 epoch 2 就到顶（0.5444），epoch 3 反而略掉；BERT 则 epoch 3 最好**。预训练更强的模型收敛更快、也更早进入小幅过拟合回退——所以必须按验证集选 epoch，不能取最后一轮。本次减量复现中两个模型 epoch 3 都仍在上涨，与参考不矛盾：减量设定下 3 epoch 仅相当于全量的 0.36 epoch 的数据量，**收敛与否应按"步数"衡量，epoch 这个单位只在"每 epoch 步数相同"的对比里才有意义**。收敛更快这一点在本次复现中依然成立：epoch 1 时 RoBERTa（0.5025）已比 BERT（0.4704）高 3.2 个点。
2. **提升几乎不花时间**：两次实验训练耗时比都约为 1.0（参考 831s vs 824s；本次 43.2min vs 51.3min）。结构/参数量完全相同——这正是选该基座做对照的意义：若拿 large（24 层）比，提升里就混入了"模型更大"的因素。
